# Custom Selections

If the built-in [selection modes](../selections/selection-modes.mdx) do not satisfy your app’s requirements, you can control the selection behavior using the [`onDayClick`](../api/react/interfaces/PropsBase.md#ondayclick) and [`modifiers`](../api/react/type-aliases/Modifiers.md) props.

| Prop         | Type                                                        | Description                               |
| ------------ | ----------------------------------------------------------- | ----------------------------------------- |
| `onDayClick` | [`DayEventHandler`](../api/react/type-aliases/DayEventHandler.md) | Callback when a day is clicked.           |
| `modifiers`  | [`Modifiers`](../api/react/type-aliases/Modifiers.md)             | An object with the modifiers of the days. |

The `onDayClick` prop is a function that receives the clicked day and its modifiers as arguments.

## How custom selection works

- Omit `mode` (or set it to `undefined`) to disable built-in selection logic.
- Keep your own selection state, derive a `selected` modifier (and any `range_*` modifiers) from it, and pass them to `modifiers` so styling/ARIA stay aligned.
- Ignore clicks on `modifiers.disabled` or `modifiers.hidden` to preserve accessibility.
- For keyboard support, handle `onDayKeyDown` (Space/Enter) in the same way as `onDayClick`.

## Style custom modifiers

Use `modifiersClassNames` or `modifiersStyles` to surface your custom state (for example, `range_middle`, `rolling`, `blocked`).

```tsx
<DayPicker
  modifiers={{ selected: value, rolling: rollingRange }}
  modifiersClassNames={{ rolling: "my-rolling" }}
  modifiersStyles={{ rolling: { background: "var(--rdp-accent-color)" } }}
/>
```

## Week numbers and starts

For week-based selections, set `weekStartsOn` (locale-aware) and provide a custom `WeekNumber` component to select a whole week when its number is clicked. Combine it with `showWeekNumber`.

```tsx
import {
  type DateRange,
  DayPicker,
  type WeekNumberProps,
} from "@solid-unstyled/daypicker";
import { createSignal } from "solid-js";

export function WeekSelection() {
  const [selectedWeek, setSelectedWeek] = createSignal<DateRange | undefined>(undefined);

  function CustomWeekNumber({ week, ...props }: WeekNumberProps) {
    return (
      <th {...props}>
        <button
          type="button"
          onClick={() =>
            setSelectedWeek({
              from: week.days[0].date,
              to: week.days[week.days.length - 1].date,
            })
          }
        >
          {props.children}
        </button>
      </th>
    );
  }

  return (
    <DayPicker
      showWeekNumber
      weekStartsOn={1}
      components={{ WeekNumber: CustomWeekNumber }}
      modifiers={{ selected: selectedWeek() }}
    />
  );
}
```

## Persisting custom selections

Serialize your custom selection state before storing or sending it.

```tsx
// Single date
const payload = selectedDate ? selectedDate.toISOString() : null;

// Multiple dates
const payload = value.map((date) => date.toISOString());

// Range
const payload =
  range?.from && range?.to
    ? { from: range.from.toISOString(), to: range.to.toISOString() }
    : null;
```
